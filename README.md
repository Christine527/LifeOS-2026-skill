# LifeOS 2026/skill
🎉欢迎使用 LifeOS！

LifeOS 是一套面向普通 Codex 用户的轻量人生行动系统。

核心是：

1.联动google日历，自主帮你定制化日程；

2.每晚交付你一份当天的日报和洞察；

3.你还可以通过查看【目标进度总览】，确认自己是否正靠近你想要的生活；


必需工具：Google 日历、Codex（另外建议配合 Obsidian）。


## 包含内容

- 10 个可组合使用的 LifeOS Skill：主入口、晨间规划、晚间复盘、目标管理、XP、日历、项目、系统体检、新用户引导与周期复盘。
- 300 条已整理的名人金句，可用于每日签名与复盘。
- 已确认的日报结构，包括「今日签名」与结尾的「查看目标进度总览」。
- 「目标进度总览」网页端与 Obsidian 端排版，并保留当前视觉结构。
- 新用户首次使用时，通过自然对话确认年龄、目标年龄、习惯和作息等个性化数据，不把示例数据当成真实数据。
- 教程署名保留：来源 @你的好友谢谢。

> 页面中展示的年龄、目标年龄、习惯和目标数据均为示例；新用户应在首次对话中替换为自己的真实信息。

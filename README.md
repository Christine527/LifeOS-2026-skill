## LifeOS 解决什么问题？

目标写了很多，真正进入今天的却很少。LifeOS 每天帮你回答：

- 现在最重要的目标是什么？
- 今天哪三件事最值得做？
- 真实日历里还有多少时间？
- 我完成的是动作，还是已经取得结果？
- 今天留下了什么证据，明天该继续还是调整？

LifeOS 不只是保存计划，而是帮助你重复完成一个行动闭环。

## 它如何运行？
>
<img width="3880" height="1431" alt="目标管理流程 plus" src="https://github.com/user-attachments/assets/ef4b6638-35a9-4fb4-a131-bedc097f5aea" />


>
>
**晨间规划：** 读取活跃目标、当前瓶颈、今日日历，筛选习惯（固定项）、杠杆任务、普通任务、挑战项。

**日历执行：** 读取已有承诺和可用时间，经确认后创建或调整日程，并在修改后回读核验；只需要计划时保持只读。

**晚间复盘：** 区分行动、结果、证据与卡点，再生成日报、结算 XP，并提出明日最多三项重点。

安装完成后，可以直接对 Codex 说：

```text
LifeOS 介绍
开始晨/晚间惯例

开始帮我复盘
帮我安排日历
查看我的日报

```

首次使用会通过七个可跳过、可续接的问题，确认作息与不可安排时间、时区、当前主线、活跃目标、人生时间线、真实习惯、日历与日报位置和 XP 偏好。未确认的信息不会由系统猜测。

## 你会得到什么？

| 输出 | 作用 |
| --- | --- |
| 晨间最多三项重点 | 把长期目标压缩成今天能执行的行动 |
| 真实日历安排 | 让重点进入真实时间，而不只停留在待办清单 |
| 晚间日报与洞察 | 分清行动、结果、证据和卡点 |
| 目标进度总览 | 查看当前主线、习惯与人生目标是否持续前进 |
| XP 与每日签名 | 为行动提供反馈，并从 300 条名人金句中选择每日签名 |

## 安装

1. 从 [最新 Release](https://github.com/Christine527/LifeOS-2026-skill/releases/latest) 下载 ZIP。
2. 将解压后的 10 个 `lifeos*` 文件夹复制到 `~/.codex/skills/`。Windows 对应 `%USERPROFILE%\.codex\skills\`。
3. 重新打开 Codex，输入 `LifeOS 新手入门`。

## 这不是什么

LifeOS 不是要求你更换全部文件夹的 Obsidian 模板，也不是把日历勾选自动当成成果的待办清单，更不会替你虚构目标、习惯和人生数据。

它的成功标准，是让你拥有经验值视野，摒弃单一结果主义思维，帮助你实现人生目标。

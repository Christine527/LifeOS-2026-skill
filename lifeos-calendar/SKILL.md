# LifeOS 日历执行

把确认过的行动放进真实时间，同时区分日历动作与项目结果。

完整读取 [references/calendar.md](references/calendar.md)。

## 工作流

1. 从 `settings.md` 读取时区、日历 ID、连接状态和可选颜色映射。
2. 使用明确的本地日期和 RFC3339 起止边界读取事件。
3. 先识别既有承诺、休息、通勤、照护和缓冲，再提出安排。
4. 修改前展示将创建或更新的事件；用户已经明确要求且目标无歧义时可直接执行。
5. 创建或更新后回读相同日期范围，核对标题、时间、数量和状态。
6. 报告实际结果；连接不可用或写入失败时保留拟定日程，不声称已同步。

## 状态规则

- 任务分类 emoji：🎯 杠杆任务 / 📋 普通任务 / 🔄 习惯
- 完成状态 emoji：🎉 完成 / ❌ 未完成
- 事件标题格式：`[分类emoji] [状态emoji] 任务名`（如 `🎯 🎉 环游世界：查非洲行程`）
- 去除重复状态标记。
- 保留描述、参与者、提醒、重复规则和颜色，除非用户要求修改。
- 取消不等于删除；只有用户明确要求删除时才删除。
- 日历 标记只证明约定行动状态，不自动证明发布、销售、交付或项目完成。

## 安全边界

- 不索取账号密码、验证码、Token 或 Cookie。
- 纯 iCloud 事件不可访问时清楚说明边界。
- 未连接时允许使用本地拟定日程，并保持 `calendar_status: pending`。
- 不根据事件标题擅自推断敏感目标或个人关系。

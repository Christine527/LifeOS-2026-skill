# LifeOS 系统体检

先诊断系统是否真的能运行。默认只读检查，不自动修复。

完整读取 [references/doctor.md](references/doctor.md)。

## 工作流

1. 确认用户正在检查哪个 LifeOS 技能 套件和哪个运行目录。
2. 检查目录与必要文件是否存在、可读且互相一致。
3. 检查首次配置状态、时区、日历、归档位置、XP 和备份状态。
4. 只读验证可选外部连接；不为了测试而创建、更新或删除真实事件。
5. 扫描公开 技能 目录是否误含个人运行数据、绝对路径、秘密值或备份。
6. 按“正常 / 降级 / 阻塞”输出证据。
7. 给出当前最值得修复的一项；只有用户明确要求修复后才修改。

## 边界

- 不输出密码、Token、Cookie、验证码或完整个人档案。
- 不把“文件存在”写成“功能已验证”。
- 不把“命令成功”写成“外部系统已生效”，需要回读证据。
- 不因可选功能缺失而判定整个 LifeOS 失败。
- 修复前先备份并明确目标文件；批量或破坏性操作必须再次确认。

# LifeOS 系统体检 检查表

系统体检 默认只读。每一项给出 “通过”、“警告” 或 “失败”，并附真实证据。

## 1. 技能 套件

- 主入口和九个子 技能 目录是否存在
- 每个目录是否包含 `SKILL.md`
- frontmatter 的 `name` 是否与目录名一致
- `agents/openai.yaml` 是否存在且默认提示包含对应 `$skill-name`
- 引用文件是否存在

## 2. 运行目录

- 运行目录是否与 技能 目录分离
- `settings.md`、`goals.md`、`routines.md`、`xp.md` 是否可读
- `projects/`、`daily-reviews/` 是否存在
- `onboarding_complete`、`onboarding_step` 和 `profile_status` 是否一致
- `pending_fields` 是否能够继续补充

## 3. 日历

- 时区是否为有效 IANA 时区
- 日历 连接状态是否明确
- 日历 ID 是否存在且不在报告中暴露账号标识
- 只读查询是否成功
- 不创建测试事件来证明连接

## 4. 写入安全

- 修改目标、XP 和配置前是否能创建备份
- 同日 XP 是否只有一条有效记录
- 目标日期的日报是否已经存在
- 日历 修改后是否有回读规则
- 运行目录是否可写但 技能 目录未混入个人数据

## 5. 隐私扫描

检查公开 技能 套件中是否出现：

- 密码、Token、Cookie、验证码或密钥
- 真实邮箱、电话、住址和账号标识
- 作者私人目标、习惯、日报、XP、截图或绝对运行路径
- 备份、缓存、日志和附件

不要在诊断报告中复述命中的完整秘密值，只报告文件、位置和类型。

## 输出

```markdown
# LifeOS 系统体检

- 总体状态：正常 / 降级 / 阻塞
- 已通过：<数量>
- 警告：<数量>
- 失败：<数量>

## 关键发现

1. <状态> <证据>

## 当前最值得修复的一项

<一个具体方向>

## 未执行

- 本次为只读检查，没有修改文件或外部系统。
```

只有用户明确要求修复后才执行修改，并在修复后重新检查。

# LifeOS 晚间复盘

把今天发生的事实整理清楚，让明天建立在真实结果上。

## 运行前

1. 检查初始化状态；未完成时保留当前请求并进入 `$lifeos-onboarding`。
2. 完整读取 [references/evening.md](references/evening.md)。
3. 读取 `settings.md`、`goals.md`、`routines.md`、当天日历或任务清单，以及最近可用日报。
4. 缺失信息保持“未记录”，不把未知写成失败或 0。

## 对话方式

- 先把日常固定项放在一组，一次询问。
- 再把晚间惯例放在一组，一次询问。
- 然后自然询问目标行动、可见结果、证据和真实卡点。
- 配置了练习记录时，保留用户原始内容与自然修正版。
- 不使用“第几题”“Q1/Q2”或审讯式连问。

## 完整收尾

同一次晚间请求中可以自然完成：

1. 整理行动、结果、证据、卡点和下一步
2. 按 `$lifeos-calendar` 规则回读并标记日历
3. 按 `$lifeos-xp` 规则保守结算且避免重复
4. 按 `$lifeos-review` 规则生成洞察和日报
5. 结合当前主线提出明日最多三项重点

不要要求用户在这些自然子步骤之间重新输入 技能 名称。

## 证据边界

- 普通行动可以由用户口述确认。
- 发布、销售、交付、部署、收入、数据变化和项目里程碑需要相应证据。
- 暂时无法验证时写“已行动 / 待验证”。
- 日历完成数不能替代项目结果。
- 写日报或 XP 前先检查同日记录和同名文件，禁止重复累计或覆盖。

# LifeOS 晨间规划

把长期目标转成今天能够执行、留下结果或证据的少数行动。

## 运行前

1. 检查 `settings.md` 和 `onboarding_complete`。
2. 初始化未完成时保留用户当前请求，先进入 `$lifeos-onboarding`。
3. 完整读取 [references/morning.md](references/morning.md)。
4. 读取 `settings.md`、`goals.md`、`routines.md`；需要承接昨天时读取最近一篇日报。
5. 日历 可用时读取当天有界日期范围；不可用时使用用户提供的任务清单并明确降级。

## 核心判断

- 同时考虑真实截止时间、生活边界、健康恢复和当前目标瓶颈。
- 每天最多选择三项高杠杆行动，不平均照顾所有长期目标。
- 优先能产生发布、交付、销售、验证或可复用资产的行动。
- 每项重点必须关联一个目标或真实责任，并写明最小证据。
- 用户状态较差时可以只保留一个重点和一个微行动。

## 交付

输出：

1. 今日判断
2. 最多三项重点行动
3. 用户自己的日常固定项
4. 每项行动的最小证据
5. 一个容易开始的微行动
6. 明确标注为“预计”的 XP 视野

只给计划时不修改 日历。用户明确要求写入时，按 `$lifeos-calendar` 的先读、确认、写入、回读规则执行。

## 边界

- 晨间只预估 XP，不提前结算。
- 不把计划写成已经发生的结果。
- 不虚构目标、固定项、空档或外部日历数据。
- 不因为目标很多就把日程塞满。

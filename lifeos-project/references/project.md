# 轻量 ISA（项目验收说明）记录模板

只为持续、多步骤、需要验收的项目使用。

```markdown
# <项目名称>

## 项目

- 状态：未开始 / 进行中 / 待验证 / 已验证 / 取消
- 服务的活跃目标：
- 用户原始目标：

## 当前状态

- 已经真实存在的内容：
- 未记录或待确认：
- 当前瓶颈：

## 理想状态

<项目完成后真实存在的结果>

## 不做什么

- 本项目范围外：
- 不能变成：

## 完成标准与证据

| 完成标准 | 验证方式 | 状态 | 证据 |
|---|---|---|---|
| 结果 1 | 文件 / 链接 / 截图 / 数据 / 明确记录 | 未开始 |  |
| 结果 2 | 文件 / 链接 / 截图 / 数据 / 明确记录 | 未开始 |  |

## 下一步

- 下一动作：
- 预计留下的最小证据：
- 需要用户决定的事项：

## 决策与学习

- YYYY-MM-DD：做了什么决定，依据是什么
- YYYY-MM-DD：什么假设被证伪，下一次如何调整
```

状态只使用：`未开始`、`进行中`、`待验证`、`已验证`、`取消`。

没有证据时可以记录行动和进展，但不能把结果标为“已验证”。

更新时：

- 新信息改变完成标准、限制或范围时，停止执行失效计划
- 用户原始目标只有在用户明确修订时才改变
- 项目完成后保留关键决策和失败路径
- 文件中只记录项目所需的最少个人信息

# LifeOS XP 结算

XP 用于反馈行动，不替代结果和证据。

完整读取 [references/xp.md](references/xp.md)。

## 工作流

1. 读取 `settings.md` 中当前 XP 规则。
2. 读取 `xp.md` 的累计值、等级、连击和同日记录。
3. 只使用用户确认、日历回读或可核验证据支持的项目。
4. 合并同一目标当天的多项行动，避免拆分刷分。
5. 区分普通推进、明显成果和关键突破。
6. 先展示明细与差异；写入前备份，已有同日记录时只更新经确认的差异。
7. 写入后重新计算累计 XP、等级与连击并回读核对。

## 边界

- 未记录不是未完成，也不是 0。
- 晨间计划只能预估，不能提前发放。
- 挑战必须由用户提前指定或明确认可。
- 没有结果证据时可以获得行动 XP，但不能获得明显成果或关键突破 XP。
- 累计 XP 永不因升级清零。
- 用户只想查询时保持只读。

# XP 规则

优先使用 `settings.md` 中用户确认的数值。没有自定义时使用以下默认值。

## 默认分值

### 固定项

- 每完成一个日常固定项：+10 XP
- 每完成一个晚间惯例：+10 XP
- 未记录不计完成，也不写成 0

### 目标行动

同一活跃目标每天只结算一个最高适用档位：

- 普通推进：+20 XP
- 明显成果：+30 XP
- 关键突破：+40～50 XP

明显成果或关键突破需要相应证据。只有行动时仍可结算普通推进。

### 挑战

- 只有用户提前指定或明确认可时：+5 XP
- 尝试但未完成也可获得
- 不与同一目标行动重复计分

### 连击

- 当日所有已配置日常固定项都完成才形成连击
- 奖励为连击天数 ×5 XP，每日最高 25 XP
- 首次达到 7 天额外 +50 XP
- 首次达到 30 天额外 +200 XP

### 等级

- 等级为 Lv.1～Lv.100
- 累计 XP 不清零
- 升到下一级所需 XP = 当前等级 ×300
- 到达 Lv.n 的累计门槛 = `150 × n × (n - 1)`

## 结算记录

```markdown
### YYYY-MM-DD
- 今日 XP：<数值>
- 明细：固定项 <数值> / 晚间惯例 <数值> / 目标行动 <数值> / 挑战 <数值> / 连击 <数值>
- 累计：<数值>
- 等级：Lv.<数值>
- 连击：<数值> 天
- 证据状态：<已确认 / 部分待验证>
- 洞察摘要：<一句话>
```

## 幂等与修正

1. 写入前查找同一日期。
2. 已有记录时计算差异，不追加第二条完整记录。
3. 展示旧值、新值和原因，得到确认后更新。
4. 更新前创建备份。
5. 写入后回读累计 XP、等级、连击和日期唯一性。
